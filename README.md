# quizup-matchmaking (staging local)

Structure cible en 2 sous-modules Maven :

- `quizup-matchmaking-domain`
- `quizup-matchmaking-infrastructure`

Seul `quizup-matchmaking-domain` est importable inter-services.

Le code applicatif reste organise sous `io.github.quizup.matchmaking.application.*` dans le module infrastructure.
